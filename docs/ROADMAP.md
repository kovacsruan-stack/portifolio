# Portfolio Roadmap

## Agora
- Manter README e documentação sincronizados com os repositórios fonte.
- Evidenciar decisões arquiteturais importantes.
- Adicionar demonstrações e screenshots quando houver interfaces estáveis.
- Melhorar cobertura de testes e QA dos projetos principais.

## Próxima etapa
- Adicionar estudos de caso por projeto.
- Adicionar exemplos sanitizados de API/arquitetura.
- Documentar fluxos de autenticação, eventos e integração com IA.
- Registrar limitações de infraestrutura de forma explícita.
- Organizar projetos acadêmicos de ADS.

## Evolução
- Projetos dedicados de SQL e análise de dados.
- Automação de processos.
- Pequenas APIs de integração.
- Experimentos de IA.
- QA e observabilidade.
- Estudos de arquitetura e performance.

## Regra
Cada novo projeto deve responder:
- qual problema resolve;
- qual é o escopo;
- quais tecnologias usa;
- quais decisões técnicas foram tomadas;
- como foi validado;
- quais limitações permanecem.

O portfólio deve crescer em profundidade, não apenas em quantidade.
