# Contributing

Este repositório é principalmente um portfólio profissional e um índice dos projetos do ecossistema KOVIAN.

## Para contribuições

1. Abra uma issue descrevendo o problema ou melhoria.
2. Explique o impacto técnico.
3. Evite incluir segredos, credenciais ou dados reais.
4. Para alterações relevantes, descreva como a mudança foi validada.
5. Mantenha a documentação coerente com o estado real do projeto.

## Segurança

Não publique:
- API keys;
- tokens;
- senhas;
- chaves privadas;
- dumps de banco;
- dados pessoais;
- logs com informações sensíveis.

Para vulnerabilidades, evite publicar detalhes exploráveis em issues públicas. Utilize um canal privado quando disponível.

## Princípio

Mudanças devem privilegiar clareza, segurança, testes e manutenção.
